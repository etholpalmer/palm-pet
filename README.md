# Palm-PET

A personal expense tracker. One screen: a cents-first keypad, today's entries, a running
total. Offline-first, installable, no accounts and no server — the data is an append-only
event log in your own browser.

Static HTML and JavaScript. No build step, no dependencies, no framework.

The eleven modules under `src/` are generated from written specifications and verified
against them before shipping; the specifications, decisions and verification records live
in a separate private repository.
